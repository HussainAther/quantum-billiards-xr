# Quantum Billiards Typography System

## Direction

The interface uses a near-future scientific-instrument language rather than a novelty sci-fi font. The display voice is condensed, architectural, and widely tracked. Telemetry uses a system monospace stack for stable numeric alignment and zero network-font dependency.

## Roles

- **Display:** `Avenir Next Condensed`, then narrow system fallbacks. Used for the title and major result headings.
- **Interface:** `Avenir Next`, then modern system sans fallbacks. Used for controls and explanatory text.
- **Telemetry:** system monospace stack. Used for values, system labels, indices, and measurements.

## Rules

1. Use uppercase labels only for compact instrumentation language.
2. Do not uppercase instructional paragraphs.
3. Use tabular monospace numerals for changing values.
4. Use tracking and hierarchy instead of glow to establish futurism.
5. Preserve readable contrast without bloom.
6. Do not add externally hosted fonts to the runtime build.
