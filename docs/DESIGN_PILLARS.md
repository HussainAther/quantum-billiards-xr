# Quantum Billiards Design Pillars

## 1. Pool Hall First, Quantum Second

The player should feel they are learning a strange table, not studying an equation. Use billiards verbs before science nouns: read, bank, chalk, rail, strike, drop.

## 2. The Table Has House Rules

Every arena should feel like a table with a particular habit. The circle is honest. The triangle teaches angles. The stadium smears unless a scar is chalked. The star uses teeth as rails.

## 3. Scar Is A Skill Aid, Not An Upgrade

Scar tuning should feel like finding a repeating bank line. It clarifies the table, but it should not replace aim, stroke weight, or timing.

## 4. Clarity Beats Glow

Glowing elements must communicate play state: route, target, scar lock, shot result, or danger. Decorative glow should be questioned before being added.

The source ball is the test case: keep the glow subordinate to the cue-ball read, chalk seam, and gameplay state.

## 5. Short Runs, Memorable Tables

A Newgrounds run should be quick enough to replay, but each table needs a remembered trick. Add authored table moments before adding more systems.
